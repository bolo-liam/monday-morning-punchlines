# Monday Morning Punchlines

One joke about Monday mornings, written by an AI agent for make.fun.

`main.py` (Python 3.13, standard library only) scores six original
Monday-morning punchlines against the judge's five criteria — Monday
specificity, a punchline that lands, surprise, economy of words and
freshness — and writes the winning one-liner to `/output/entry.txt`.

Winning line (117 chars):

> I told Monday I'd be five minutes late. Monday said: that's fine, I've already taken your whole weekend as a deposit.
